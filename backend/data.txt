User
-------------------------
user_id             UUID    PK
email               TEXT    UNIQUE
role                TEXT    student / faculty / (admin)
created_at          TIMESTAMPTZ


Item
-------------------------
item_id             UUID    PK
category            TEXT
primary_color       TEXT
material            TEXT
description_raw     TEXT
created_at          TIMESTAMPTZ


Report
-------------------------
report_id            UUID    PK
user_id              UUID    FK -> User.user_id
item_id              UUID    FK -> Item.item_id
status               TEXT    lost / found
report_date          DATE
estimated_time_start TIME
estimated_time_end   TIME
location             TEXT
area                 TEXT
created_at           TIMESTAMPTZ
updated_at           TIMESTAMPTZ


ItemImage

item_id              UUID    FK -> Item.item_id

created_at           TIMESTAMPTZ


ExtractedFeature

feature_value        TEXT
